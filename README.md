# Application Shiny – Messi vs Ronaldo

Ce projet est une application interactive développée avec **R Shiny**, permettant de comparer les buts marqués par **Lionel Messi** et **Cristiano Ronaldo** tout au long de leur carrière.

##  Objectif

Analyser et visualiser les performances des deux légendes du football à travers :

- Le nombre de buts par **saison**
- Les buts par **club**
- La répartition par **compétition**

##  Technologies utilisées

- **R**  
- **Shiny**  
- **ggplot2** pour les visualisations  
- **plotly** pour les graphiques interactifs  
- **shinyapps.io** pour le déploiement
